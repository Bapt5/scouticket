## L’essentiel {#essentiel}

Ces deux fonctionnalités sont disponibles dans tous les groupes, sans réglage. Elles allègent le travail de la trésorerie : moins de relances, moins de justificatifs perdus, car les justificatifs arrivent au fil de l’eau au lieu de s’accumuler en fin de mois.

## Aller plus loin (optionnel) {#options}

::: tip Chaque fonctionnalité est optionnelle
Le responsable de groupe les active ou non dans _Paramètres du groupe_. Un groupe qui n’en a pas besoin garde l’envoi simple décrit plus haut. Vous pouvez en activer une seule, ou plusieurs avec le temps.
:::

Certaines options en supposent une autre :

## Rejoindre un groupe {#rejoindre-un-groupe}

Vous êtes membre d’un groupe ? Demandez simplement à votre responsable de vous envoyer une invitation. Ne créez pas de groupe vous-même : une fois l’invitation acceptée, vous pourrez envoyer vos justificatifs dans le bon groupe.
